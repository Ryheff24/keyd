Absence is from inspecting the complete factories (WTm:247–287; WTi:327–366), not an assertion about OS defaults or negotiated state. [Apple option definitions](https://developer.apple.com/documentation/network/nwprotocoltcp/options).
[C] TLS minimum1.3, identity/certificate verification, no explicit maximum version or record-size override (WTm:251–280; WTi:328–347). Media and controls share the TLS/TCP connection; sends contain a4-byte length prefix, use default context with complete=true on Mac (WTm:616–636), and contentProcessed on iPad (WTi:568–576). No application TLS-record sizing; 16384-byte callbacks do not prove record boundaries. Receive ranges: Mac **1..65536** bytes (WTm:1119), iPad **1..262144** (WTi:145,989); maximum is a cap, not a fill requirement ([Apple receive contract](https://developer.apple.com/documentation/network/nwconnection/receive(minimumincompletelength:maximumlength:completion:))). Each rearms after synchronous drain (WTi:1023,1048); log callback/drain/rearm durations to bound that gap.
[I] Five3–9KB frames are several TCP segments, not five segments; flight size can still shrink to one lost tail, or reverse ACK data can have a tiny flight. A lost tail with no later delivery cannot supply duplicate/SACK feedback; **RTO fallback is possible**, including after failed/ineligible TLP. It is not established merely by a one-second duration, especially because six cases have already delivered all media and may instead time out iPad→Mac application ACK data.
[R] Public XNU `tcp_timer.h` defines non-local base minimum `TCP_RETRANSHZ/33` (~30ms), documents local100ms, established-connection200ms slop, and100ms-class retransmit timer scheduling; initial RTO1s is **not a universal established minimum**. Actual timer uses smoothed RTT/variance, floors, slop and backoff; installed macOS/iPadOS values are unverified. [Header](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/netinet/tcp_timer.h), [formula](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/netinet/tcp_var.h#L1886-L1904). [R] TLP exists: `tcp_set_pto` requires established/SACK-enabled/non-recovery, no prior RTO/probe/reordering exclusions; link heuristics can suppress it.
