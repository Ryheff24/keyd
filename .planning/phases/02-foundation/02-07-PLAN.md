    **SessionManager.h / SessionManager.m:**

    `@interface SessionManager : NSObject`
    - Owns: `ScreenCapture *capture`, `FrameCompressorState compressor`, `HEVCEncoder *hevcEncoder`, `USBNetworkTransport *usbTransport`, `WirelessTransport *wirelessTransport`, `PairingManager *pairing`.
    - Session state enum: `SESSION_AWAITING_PERMISSIONS`, `SESSION_AWAITING_PAIRING`, `SESSION_CONNECTING`, `SESSION_STREAMING`, `SESSION_RECONNECTING`, `SESSION_STOPPED`.
    - Transport FSM state: `TransportState currentTransport`.

    `- (void)start`:
    1. Check Screen Recording: `CGPreflightScreenCaptureAccess()`. If false, `CGRequestScreenCaptureAccess()`. Poll every 3 seconds until granted (RD-AGENT-04).
    2. Check Accessibility: `AXIsProcessTrustedWithOptions(@{kAXTrustedCheckOptionPrompt: @YES})`. Poll every 3 seconds until granted (RD-AGENT-05).
    3. Once BOTH granted, transition to AWAITING_PAIRING.
    4. If already paired (check Keychain), skip to CONNECTING.
    5. If not paired, generate QR payload and notify StatusBarController to show "Pair iPad..." as actionable.
    6. On pairing complete, transition to CONNECTING.
    7. Start transport monitoring (USB NCM path monitor + Bonjour listener).
    8. On connection established, send session handshake (SessionHandshakeMessage with display geometry).
    9. Start capture, begin frame delivery via onFrame callback.

    `- (void)handleTransportEvent:(TransportEvent)event`:
    - Feed to FSM: `transport_fsm_transition(currentTransport, event)`.
    - Execute effects: switch encode mode, rebind sockets, update StatusBarController.
    - On HEVC mode: stop FrameCompressor, start HEVCEncoder.
    - On LZ4 mode: stop HEVCEncoder, start FrameCompressor.

    Frame delivery callback:
    - LZ4 mode: CompressOutput from FrameCompressor -> prepend MediaFrameHeader -> send via usbTransport.sendMediaFrame.
    - HEVC mode: encoded NAL from HEVCEncoder -> prepend MediaFrameHeader -> send via active transport.

    Reconnection: On disconnect, freeze state to RECONNECTING. Exponential backoff retry (intervals at Claude's discretion — suggest 0.5s, 1s, 2s, 4s, 8s max). On reconnect, resume streaming.
