<objective>
Transport layer: USB NCM, Wi-Fi, AWDL, failover FSM on both sides

Purpose: The transport layer is the data highway between Mac and iPad. It detects USB NCM interfaces, establishes UDP (media) and TCP (input) connections, discovers wireless alternatives via Bonjour, and orchestrates automatic failover/promotion via a pure state machine. Without this, captured frames have nowhere to go.

Output: Transport modules for both macOS (C+ObjC) and iPadOS (Swift) with USB NCM detection, Wi-Fi/AWDL fallback, and a pure FSM controlling transitions.
</objective>

    **TransportFSM.h / TransportFSM.c (pure C, no ObjC):**

    Define states: `TRANSPORT_IDLE`, `TRANSPORT_USB_NCM`, `TRANSPORT_WIFI`, `TRANSPORT_AWDL`, `TRANSPORT_DISCONNECTED`.

    Define events: `TRANSPORT_EVT_WIRED_APPEARED`, `TRANSPORT_EVT_WIRED_DISAPPEARED`, `TRANSPORT_EVT_WIFI_AVAILABLE`, `TRANSPORT_EVT_WIFI_UNAVAILABLE`, `TRANSPORT_EVT_AWDL_AVAILABLE`, `TRANSPORT_EVT_AWDL_UNAVAILABLE`, `TRANSPORT_EVT_CONNECTED`, `TRANSPORT_EVT_DISCONNECTED`, `TRANSPORT_EVT_ERROR`.

    Define effects (side-effect enum): `EFFECT_BIND_USB_NCM`, `EFFECT_CONNECT_WIFI`, `EFFECT_CONNECT_AWDL`, `EFFECT_DISCONNECT_CURRENT`, `EFFECT_SWITCH_ENCODE_LZ4`, `EFFECT_SWITCH_ENCODE_HEVC`, `EFFECT_NOTIFY_TRANSPORT_CHANGE`.

    `TransportTransition` struct: `TransportState next_state`, `TransportEffect effects[4]`, `int effect_count`.

    `transport_fsm_transition(TransportState current, TransportEvent event)` -> `TransportTransition`. Pure function, no side effects. Implements transition table:
    - IDLE + WIRED_APPEARED -> USB_NCM, effects: [BIND_USB_NCM, SWITCH_ENCODE_LZ4, NOTIFY]
    - USB_NCM + WIRED_DISAPPEARED -> WIFI, effects: [DISCONNECT_CURRENT, CONNECT_WIFI, SWITCH_ENCODE_HEVC, NOTIFY]
    - WIFI + WIFI_UNAVAILABLE -> AWDL, effects: [DISCONNECT_CURRENT, CONNECT_AWDL, NOTIFY]
    - Any + WIRED_APPEARED -> USB_NCM, effects: [DISCONNECT_CURRENT, BIND_USB_NCM, SWITCH_ENCODE_LZ4, NOTIFY] (promote immediately)
    - WIFI + WIRED_APPEARED -> USB_NCM (same as above)
    - AWDL + WIRED_APPEARED -> USB_NCM (same as above)

    Pattern copied from keyd v1.0 TransportStateMachine.swift but in C.

    **USBNetworkTransport.h / USBNetworkTransport.m (ObjC, wrapping Network.framework C API):**

    `@interface USBNetworkTransport : NSObject`
    - Properties: `nw_connection_t mediaConnection` (UDP), `nw_connection_t inputConnection` (TCP), `nw_interface_t activeInterface`, `BOOL isConnected`.
    - `onMediaReceived` callback block: receives raw bytes for media frames.
    - `onInputReceived` callback block: receives raw bytes for input events.
    - `sendMediaFrame:(const void*)data length:(size_t)len` — sends over UDP.
    - `sendInputEvent:(const void*)data length:(size_t)len` — sends over TCP.

    Implementation:
    - `nw_path_monitor_t` created with `nw_path_monitor_create_with_type(nw_interface_type_wired)`.
    - Path update handler: enumerate interfaces, find wiredEthernet, store exact `nw_interface_t` object (NEVER hardcode name per Pitfall 2/6).
    - `bindToInterface:` creates NWConnection for UDP on KEYDRD_MEDIA_PORT and TCP on KEYDRD_INPUT_PORT, both with `nw_parameters_set_required_interface(params, interface)`.
    - Mac is the LISTENER side: create `nw_listener_t` for UDP on KEYDRD_MEDIA_PORT and TCP on KEYDRD_INPUT_PORT, bound to the USB NCM interface.
    - Receive loop: schedule `nw_connection_receive` recursively for both connections.

    **WirelessTransport.h / WirelessTransport.m (ObjC):**

    `@interface WirelessTransport : NSObject`
    - `nw_listener_t bonjourListener` — advertises `_keydrd._tcp` service for iPad to discover.
    - `nw_connection_t mediaConnection` (UDP), `nw_connection_t inputConnection` (TCP).
    - `startAdvertising` — create NWListener with Bonjour on `_keydrd._tcp` (RD-TRANS-10).
    - `includePeerToPeer = true` on NWParameters for AWDL support (RD-TRANS-03).
    - Same send/receive API as USBNetworkTransport.
    - When connection accepted, determine if Wi-Fi or AWDL via interface type on the connection and feed appropriate event to FSM.

    **Protocol.swift — Swift mirror of protocol.h structs:**

    ```swift
    struct MediaFrameHeader {
        let magic: UInt16
        let flags: UInt8
        let seq: UInt32
        let chunkIdx: UInt16
        let chunkTotal: UInt16
        let payloadSize: UInt32
        let tsUs: UInt64
        let crc32: UInt32

        var isHEVC: Bool { flags & 0x01 != 0 }
        var isKeyframe: Bool { flags & 0x02 != 0 }
        var isLastChunk: Bool { flags & 0x04 != 0 }
        var isDelta: Bool { flags & 0x40 != 0 }

        static let size = 24
        static func parse(from data: Data) -> MediaFrameHeader? {
            guard data.count >= Self.size else { return nil }
            return data.withUnsafeBytes { $0.load(as: MediaFrameHeader.self) }
        }
    }
    ```

    Similarly mirror `InputEventHeader` and `SessionHandshakeMessage`.
    Add constants: `keydrdMagic = 0x4B44`, `keydrdService = "_keydrd._tcp"`, `keydrdMediaPort = 14567`, `keydrdInputPort = 14568`.

    **TransportFSM.swift — Pure Swift FSM (mirrors C version):**

    Same states, events, effects as TransportFSM.c. Pure function `transition(from:on:) -> (state: TransportState, effects: [TransportEffect])`. No side effects in the function. Pattern-copied from keyd v1.0 TransportStateMachine.swift.

    **USBNetworkTransport.swift:**

    - `NWPathMonitor(requiredInterfaceType: .wiredEthernet)` to detect USB NCM.
    - On path update: extract exact `NWInterface` from `path.availableInterfaces.first(where: { $0.type == .wiredEthernet })` (NEVER just use type — need exact object per Pitfall 2).
    - `connectOverUSBNCM(interface: NWInterface)`: create `NWConnection` for UDP on KEYDRD_MEDIA_PORT with `NWParameters.init(dtls:udp:)`, set `params.requiredInterface = interface`.
    - Create separate `NWConnection` for TCP on KEYDRD_INPUT_PORT with `NWParameters.init(tls:tcp:)`, set `params.requiredInterface = interface`.
    - iPad is the CONNECTOR side: connect to Mac's link-local address on the USB NCM interface.
    - Schedule receive loops on both connections.
    - `sendInputEvent(_ data: Data)` — sends over TCP.
    - `onMediaFrame: ((Data) -> Void)?` callback — fires when UDP media data received.

    - `includePeerToPeer = true` in browse descriptor for AWDL (RD-TRANS-03).
    - When result found, create NWConnection to the discovered endpoint.
    - Determine Wi-Fi vs AWDL via `connection.currentPath?.localEndpoint` interface type.
    - Same send/receive API pattern as USBNetworkTransport.swift.
    - Feed FSM events based on browse results and connection state changes.
