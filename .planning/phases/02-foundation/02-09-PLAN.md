    **Add resolution match message type to protocol.h:**
    Add to InputEventHeader type values:
    - `0x21 = resolution_match_request` (iPad -> Mac: request Mac to change resolution to match iPad aspect ratio)
    - `0x22 = resolution_match_response` (Mac -> iPad: confirmation with new geometry)
    - `0x23 = geometry_update` (Mac -> iPad: new display geometry notification after resolution change)

    **Update `SessionManager.m` to wire the full Mac-side pipeline:**

    **Session handshake (sent after connection, before first frame):**
    1. When transport connection is established (USB NCM or wireless), send `SessionHandshakeMessage` over TCP input channel:
       ```objc
       SessionHandshakeMessage handshake = {
           .magic = KEYDRD_MAGIC,
           .msg_type = 0x01,
           .display_width = (uint32_t)displayWidth,
           .display_height = (uint32_t)displayHeight,
           .scale_factor = (float)scaleFactor,
           .aspect_ratio = (float)displayWidth / (float)displayHeight,
           .capabilities = 0x07,  // LZ4 + HEVC + eco available
           .max_fps = 120,
           .agent_version = 1,
           .reserved = 0
       };
       [self.activeTransport sendInputEvent:&handshake length:sizeof(handshake)];
       ```
    2. Get display geometry from `CGMainDisplayID()`: `CGDisplayPixelsWide`, `CGDisplayPixelsHigh`, `CGDisplayScreenSize` for scale factor.

    **Frame pipeline wiring:**
    1. Set ScreenCapture.onFrame callback:
       ```objc
       self.capture.onFrame = ^(CompressOutput *output) {
           // Prepend header to payload and send over UDP
           NSMutableData *packet = [NSMutableData dataWithBytes:&output->header length:sizeof(MediaFrameHeader)];
           [packet appendBytes:output->buf length:output->compressed_size];
           [self.activeTransport sendMediaFrame:packet.bytes length:packet.length];
       };
       ```
    2. Start capture after handshake sent.

    **Transport failover integration:**
    Update `handleTransportEvent:` to:
    - On switch to USB NCM: deactivate HEVCEncoder, reactivate FrameCompressor (LZ4+delta). Rebind ScreenCapture.onFrame to compress path.
    - On switch to Wi-Fi/AWDL: deactivate FrameCompressor, activate HEVCEncoder. Redirect ScreenCapture to pass CVPixelBuffer to HEVCEncoder instead of FrameCompressor.
    - Send transport change notification to iPad via TCP (InputEventHeader with type=0x20 mode_change).

    **Resolution matching handler (triggered by iPad "Match iPad Resolution" button):**
    On receiving `InputEventHeader` type=0x21 (resolution_match_request) from iPad:
    1. Store the current display mode for revert: `CGDisplayCopyDisplayMode(CGMainDisplayID())`.
    2. Get all available display modes: `CGDisplayCopyAllDisplayModes(CGMainDisplayID(), NULL)`.
    3. Find the best match for iPad's aspect ratio (iPad reports its screen dimensions in the 0x21 payload: 8 bytes = uint32 width + uint32 height after the InputEventHeader).
    4. Apply via `CGDisplaySetDisplayMode(CGMainDisplayID(), bestMode, NULL)`.
    5. If successful: update capture with new geometry, send `geometry_update` (0x23) to iPad with new width/height/scale.
    6. If no suitable mode found or failed: send `resolution_match_response` (0x22) with error flag.
    7. On session disconnect: revert to stored display mode via `CGDisplaySetDisplayMode(CGMainDisplayID(), storedMode, NULL)`.

    **Eco mode toggle:**
    - On eco mode requested (via TCP from iPad or local menu bar):
      1. Activate HEVCEncoder at reduced resolution (1080p) and 30fps.
      2. Update SCStreamConfiguration with reduced width/height and `minimumFrameInterval = CMTimeMake(1, 30)`.
      3. Reconfigure SCStream with new config.

    **Reconnection:**
    - On disconnect: stop capture to avoid wasting CPU. Revert resolution if changed.
    - On reconnect: re-send handshake, restart capture.

    **Frame receive pipeline (already outlined in Plan 08, now fully implemented):**
    ```swift
    func handleReceivedFrame(_ data: Data) {
        guard data.count >= MediaFrameHeader.size else { return }
        guard let header = MediaFrameHeader.parse(from: data) else { return }
        guard header.magic == keydrdMagic else { return }

        let payload = data.dropFirst(MediaFrameHeader.size)

        if header.isHEVC {
            hevcDecoder.decode(data: Data(payload), header: header)
            // onDecodedFrame callback updates MetalRenderer
        } else {
            let frameBytes = macDisplayWidth * macDisplayHeight * 4
            if let ptr = lz4Decompressor.decompress(
                data: Data(payload), header: header, frameBytes: frameBytes) {
                metalRenderer.updateFrame(ptr, width: macDisplayWidth, height: macDisplayHeight)
            }
        }

        // Update HUD metrics
        hudViewModel.fps = computeCurrentFPS()
        hudViewModel.latencyMs = computeLatency(fromTimestamp: header.tsUs)
    }
    ```

    **Resolution match request (triggered by HUD "Match iPad Resolution" button):**
    ```swift
    func requestResolutionMatch() {
        // Send InputEventHeader type=0x21 with iPad screen dimensions
        var header = InputEventHeader(type: 0x21, ts_us: currentTimestampUs())
        var payload = Data()
        payload.append(contentsOf: withUnsafeBytes(of: UInt32(iPadScreenWidth)) { Array($0) })
        payload.append(contentsOf: withUnsafeBytes(of: UInt32(iPadScreenHeight)) { Array($0) })
        var headerData = Data(bytes: &header, count: MemoryLayout<InputEventHeader>.size)
        headerData.append(payload)
        activeTransport.sendInputEvent(headerData)
    }
    ```
