    **macOS side (C Network.framework API):**

    Modify USBNetworkTransport.m TCP connection creation:
    ```objc
    nw_parameters_t tcpParams = nw_parameters_create_secure_tcp(
        ^(nw_protocol_options_t tls_options) {
            sec_protocol_options_t sec = nw_tls_copy_sec_protocol_options(tls_options);
            sec_protocol_options_set_min_tls_protocol_version(sec, tls_protocol_version_TLSv13);
            // Certificate pinning: verify block rejects unknown certs
            sec_protocol_options_set_verify_block(sec, ^(sec_protocol_metadata_t metadata,
                sec_trust_t trust, sec_protocol_verify_complete_t complete) {
                // Compare peer cert against stored paired cert from Keychain
                BOOL trusted = [self verifyPeerCertificate:trust];
                complete(trusted);
            }, dispatch_get_main_queue());
        },
        NW_PARAMETERS_DEFAULT_CONFIGURATION
    );
    ```

    Modify USBNetworkTransport.m UDP connection creation:
    ```objc
    nw_parameters_t udpParams = nw_parameters_create_secure_udp(
        ^(nw_protocol_options_t dtls_options) {
            sec_protocol_options_t sec = nw_tls_copy_sec_protocol_options(dtls_options);
            sec_protocol_options_set_min_tls_protocol_version(sec, tls_protocol_version_TLSv13);
            // Same cert pinning verify block
        },
        NW_PARAMETERS_DEFAULT_CONFIGURATION
    );
    ```

    Apply same pattern to WirelessTransport.m NWListener and NWConnection creation.

    Add helper method `verifyPeerCertificate:(sec_trust_t)trust` that loads the stored peer certificate from Keychain (using `KEYDRD_KEYCHAIN_SERVICE`) and compares against the presented certificate. Reject if no stored cert (not yet paired) or if cert doesn't match.

    CRITICAL: No fallback to plaintext. If TLS/DTLS handshake fails, connection fails. No `NW_PARAMETERS_DISABLE_PROTOCOL` for security.

    **macOS PairingManager.h / PairingManager.m (ObjC):**

    Pattern-copy from keyd v1.0 `macOS/KeydAgent/Pairing/PairingManager.swift` but rewrite in ObjC.

    `@interface PairingManager : NSObject`
    - `@property (nonatomic, readonly) BOOL isPaired`
    - `@property (nonatomic, readonly) NSData *sharedSecret`
    - `- (NSString *)generateQRPayload` — generates QR code string containing:
      1. Mac's Curve25519 public key (base64)
      2. Display geometry (width, height, scale factor)
      3. Protocol version (1)
      4. Service name (_keydrd._tcp)
      Format: JSON for QR payload only (this is the ONE place JSON is used; all subsequent communication is binary).
    - `- (BOOL)completePairing:(NSData *)iPadPublicKey` — performs ECDH key agreement, derives shared secret, stores in Keychain under `KEYDRD_KEYCHAIN_SERVICE`.
    - `- (void)resetPairing` — deletes Keychain entry.
    - `- (NSData *)loadStoredPeerCertificate` — loads stored peer cert for cert pinning.

    Use Security.framework for key generation:
    - `SecKeyCreateRandomKey` with `kSecAttrKeyTypeECSECPrimeRandom` (Curve25519 equivalent via SecKey, or use raw `CC_EC` if needed).
    - Alternative: Use the CommonCrypto / CryptoKit bridge pattern. Since this is ObjC, use `SecKeyCreateWithData` and `SecKeyCopyKeyExchangeResult` with `kSecKeyAlgorithmECDHKeyExchangeStandard`.
    - Store derived shared secret in Keychain with service `KEYDRD_KEYCHAIN_SERVICE`, account `"pairing"`.

    Generate self-signed TLS identity from the shared secret for use in TLS/DTLS connections. Store identity in Keychain.

    **iPadOS QRPairing.swift:**

    Pattern-copy from keyd v1.0 pairing but with new service name.

    `class QRPairing: NSObject, AVCaptureMetadataOutputObjectsDelegate`:
    - `AVCaptureSession` with back camera, metadata output for `.qr`.
    - `func startScanning()` — starts camera session, shows viewfinder.
    - `metadataOutput(_:didOutput:from:)` — parses QR JSON payload, extracts Mac's public key and display geometry.
    - `func completePairing(macPublicKeyB64: String)`:
      1. Generate iPad's Curve25519 key pair via `CryptoKit.Curve25519.KeyAgreement.PrivateKey()`.
      2. Decode Mac's public key from base64.
      3. Perform ECDH: `iPadPrivateKey.sharedSecretFromKeyAgreement(with: macPublicKey)`.
      4. Derive symmetric key via HKDF.
      5. Store in Keychain under `KEYDRD_KEYCHAIN_SERVICE`.
    - `func sendPublicKeyToMac(_ publicKey: Data)` — sends iPad's public key back to Mac over TCP (initial pairing connection before TLS is established — this one connection uses a temporary pre-shared key or is done via a side channel).
    - `var isPaired: Bool` — checks Keychain for stored secret.
    - `func resetPairing()` — deletes Keychain entry.
    - Store display geometry from QR payload for use in rendering setup.

    NOTE on pairing bootstrap: The initial pairing exchange happens before TLS is established. The QR code is the trust anchor (physical proximity). After pairing, generate self-signed certificates from the shared secret and use them for all TLS/DTLS connections going forward.
