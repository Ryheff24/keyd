  <name>Task 1: FrameCompressor — LZ4+delta compression hot path (pure C)</name>
  <files>

  </files>
  <action>
    Create `FrameCompressor.h` and `FrameCompressor.c` as pure C (no ObjC) for the hot path.

    FrameCompressor.h:
    - `#pragma once`
    - `#include "protocol.h"`, `#include "delta.h"`, `#include "lz4.h"`
    - `#include <IOSurface/IOSurface.h>`, `#include <CoreMedia/CoreMedia.h>`
    - `CompressOutput` struct: `uint8_t *buf` (pre-allocated), `size_t buf_capacity`, `size_t compressed_size`, `MediaFrameHeader header`.
    - `FrameCompressorState` struct: `DeltaBuffer delta_buf`, `uint32_t seq` (frame counter), `uint32_t keyframe_interval_frames` (default 120 = ~1s at 120fps), `CompressOutput output`, `dispatch_queue_t compress_queue`.
    - Functions: `frame_compressor_init(FrameCompressorState*, size_t frame_bytes)`, `frame_compressor_destroy(FrameCompressorState*)`, `compress_frame(FrameCompressorState*, IOSurfaceRef surface, CMSampleBufferRef sampleBuf, CompressOutput *out)`.

    FrameCompressor.c:
    - `frame_compressor_init`: malloc output buffer of `LZ4_COMPRESSBOUND(frame_bytes)` capacity. Initialize DeltaBuffer via `delta_buffer_init`. Set seq=0. Create high-priority dispatch queue `"com.keydrd.compress"`.
    - `frame_compressor_destroy`: free output buffer, destroy DeltaBuffer.
    - `compress_frame`:
      1. `IOSurfaceLock(surface, kIOSurfaceLockReadOnly, NULL)` — lock IOSurface for read.
      2. Get `base = IOSurfaceGetBaseAddress(surface)` and `bytes = IOSurfaceGetAllocSize(surface)`.
      3. Decide keyframe vs delta: every `keyframe_interval_frames` frames, OR if this is the first frame (seq==0), send keyframe. Otherwise compute delta.
      4. **Keyframe path**: `LZ4_compress_default(base, out->buf, bytes, out->buf_capacity)`. Set header flags bit1=keyframe. Call `update_keyframe_reference(&state->delta_buf, base)` to update reference.
      5. **Delta path**: `compute_delta(&state->delta_buf, base, temp_delta_buf)`. Then `LZ4_compress_default(temp_delta_buf, out->buf, bytes, out->buf_capacity)`. Set header flags bit6=delta. If `compressed_size > 0.6 * last_keyframe_compressed_size`, discard delta and send keyframe instead (RD-COMP-03 threshold).
      6. `IOSurfaceUnlock(surface, kIOSurfaceLockReadOnly, NULL)`.
      7. NOTE: Caller MUST hold CMSampleBuffer retain until this function returns (RD-COMP-05). Document this in the header comment.
      8. Fill `out->header`: magic=KEYDRD_MAGIC, seq=state->seq++, chunk_idx=0, chunk_total=1 (chunking deferred to transport layer), payload_size=compressed_size, ts_us from CMSampleBufferGetPresentationTimeStamp, crc32 of payload.
    - Pre-allocate a temp delta buffer (same size as frame) in init — do NOT malloc per frame.
    - Use `dispatch_assert_queue(state->compress_queue)` at entry to enforce single-threaded access on compress queue.
  </action>

  <name>Task 2: ScreenCapture — SCStream delegate with frame watchdog</name>
  <files>
    RemoteDesktop/macOS/Capture/ScreenCapture.h

  </files>
  <action>
    Create `ScreenCapture.h` and `ScreenCapture.m` (Objective-C, wrapping SCKit).

    ScreenCapture.h:
    - `#import <ScreenCaptureKit/ScreenCaptureKit.h>`
    - `#import <CoreMedia/CoreMedia.h>`
    - `#import "FrameCompressor.h"`
    - `ScreenCaptureFrameCallback` typedef: block receiving `(CompressOutput *output)` — called after compression with ready-to-send frame.
    - `@interface ScreenCapture : NSObject <SCStreamOutput>`
    - Properties: `@property (nonatomic, assign) BOOL isCapturing`, `@property (nonatomic, copy) ScreenCaptureFrameCallback onFrame`, `@property (nonatomic, assign, readonly) BOOL hasPermission`.
    - Methods: `- (void)startCapture`, `- (void)stopCapture`, `- (void)requestPermission:(void(^)(BOOL granted))completion`.

    ScreenCapture.m:
    - Strong ivar for `SCStream *stream` (Pitfall 7: SCStream holds delegate weakly in Sonoma+ — we must store stream strongly, and self is stored strongly by the stream as output not delegate, but store stream reference strongly anyway).
    - Strong ivar for `FrameCompressorState compressor`.
    - `dispatch_queue_t captureQueue` — high priority serial queue `"com.keydrd.capture"`.
    - `dispatch_queue_t compressQueue` — high priority serial queue `"com.keydrd.compress"`.
    - Frame watchdog: `dispatch_source_t watchdogTimer`, fires every 2 seconds. If no frame received in last 2 seconds AND display is not sleeping (check via `CGDisplayIsAsleep(CGMainDisplayID())`), set a `needsReauthorization` flag and call `onReauthorizationNeeded` callback.
    - `requestPermission:` — call `CGPreflightScreenCaptureAccess()`. If false, call `CGRequestScreenCaptureAccess()`. Return result via completion block.
    - `startCapture`:
      1. Call `[SCShareableContent getShareableContentWithCompletionHandler:]` on background queue (can block 3-10s on Sequoia per Pitfall 1).
      2. Find primary display from `content.displays`.
      3. Create `SCStreamConfiguration`: `pixelFormat = kCVPixelFormatType_32BGRA` (RD-CAP-06), `minimumFrameInterval = CMTimeMake(1, 120)` (RD-CAP-02), `queueDepth = 3`, `showsCursor = YES`, `width = display.width`, `height = display.height`.
      4. Create `SCContentFilter` with the display and no excluded apps.
      5. Create `SCStream` with config and filter. Store strongly.
      6. `[stream addStreamOutput:self type:SCStreamOutputTypeScreen sampleHandlerQueue:captureQueue]`.
      7. `[stream startCaptureWithCompletionHandler:]`.
      8. Initialize `frame_compressor_init(&compressor, display.width * display.height * 4)` (BGRA = 4 bytes/pixel).
      9. Start watchdog timer.
    - `stream:didOutputSampleBuffer:ofType:`:
      1. If type != SCStreamOutputTypeScreen, return.
      2. Update last frame timestamp for watchdog.
      3. Get `CVPixelBufferRef pixelBuffer = CMSampleBufferGetImageBuffer(sampleBuffer)`.
      4. Get `IOSurfaceRef surface = CVPixelBufferGetIOSurface(pixelBuffer)`.
      5. `CFRetain(sampleBuffer)` — hold retain (RD-COMP-05).
      6. Dispatch to compressQueue: call `compress_frame(&compressor, surface, sampleBuffer, &output)`. Call `self.onFrame(&output)`. Then `CFRelease(sampleBuffer)` AFTER compress returns.
    - `stopCapture`: stop stream, invalidate watchdog, destroy compressor.
  </action>
