    - `#pragma once` guard

    - `MediaFrameHeader` struct (24 bytes, `__attribute__((packed))`): magic(u16), flags(u8), seq(u32), chunk_idx(u16), chunk_total(u16), payload_size(u32), ts_us(u64), crc32(u32). flags bit layout: bit0=HEVC, bit1=keyframe, bit2=last_chunk, bit6=delta.
    - `InputEventHeader` struct (9 bytes, `__attribute__((packed))`): type(u8), ts_us(u64). type values: 0x01=mouse_move, 0x02=click, 0x03=scroll, 0x10=key, 0x20=mode_change, 0x30=keepalive, 0xFF=latency_probe.
    - `SessionHandshakeMessage` struct (`__attribute__((packed))`): magic(u16), msg_type(u8, 0x01=session_handshake), display_width(u32), display_height(u32), scale_factor(float), aspect_ratio(float), capabilities(u8, bit0:LZ4 bit1:HEVC bit2:eco_available), max_fps(u8), agent_version(u8), reserved(u32).
    - Add `_Static_assert(sizeof(MediaFrameHeader) == 24, ...)` and `_Static_assert(sizeof(InputEventHeader) == 9, ...)`.

    Create `RemoteDesktop/Shared/crypto.h`:

    - `#define KEYDRD_KEYCHAIN_SERVICE "com.ryheff.keyd.remote.agent"`
    - `#define KEYDRD_AGENT_BUNDLE_ID "com.ryheff.keyd.remote.agent"`
    - `#define KEYDRD_APP_BUNDLE_ID "com.ryheff.keyd.remote.app"`

    Vendor LZ4 v1.10.0 block API (requires internet access):
    - Download `lz4.c` and `lz4.h` using explicit raw URLs:
      ```bash
      curl -fSL -o RemoteDesktop/Shared/lz4.c \
        "https://raw.githubusercontent.com/lz4/lz4/v1.10.0/lib/lz4.c"
      curl -fSL -o RemoteDesktop/Shared/lz4.h \
        "https://raw.githubusercontent.com/lz4/lz4/v1.10.0/lib/lz4.h"
      ```
    - Verify the downloaded files contain `LZ4_compress_default` and `LZ4_decompress_safe` functions (block API): `grep -q 'LZ4_compress_default' RemoteDesktop/Shared/lz4.c && echo "LZ4 OK"`.
    - Do NOT include lz4frame.c/h or lz4hc.c/h — block API only.
    - If download fails, error out explicitly — do not proceed with missing LZ4 files.

    Create `RemoteDesktop/Shared/delta.h`:
    - `#pragma once`
    - `#include <stddef.h>`, `#include <stdint.h>`, `#include <pthread.h>`
    - `DeltaBuffer` struct: `uint8_t *buf[2]`, `int active`, `pthread_rwlock_t lock`, `size_t frame_bytes`.
    - Function declarations: `delta_buffer_init(DeltaBuffer*, size_t frame_bytes)`, `delta_buffer_destroy(DeltaBuffer*)`, `compute_delta(DeltaBuffer*, const void *current, void *delta_out)`, `apply_delta(const void *delta, const void *prev_keyframe, void *output, size_t frame_bytes)`, `update_keyframe_reference(DeltaBuffer*, const void *keyframe)`.

    Create `RemoteDesktop/Shared/delta.c`:
    - `#include "delta.h"`, `#include <string.h>`
    - `delta_buffer_init`: malloc two buffers of `frame_bytes`, memset to 0, init pthread_rwlock, set active=0.
    - `delta_buffer_destroy`: free both buffers, destroy pthread_rwlock.
    - `compute_delta`: take read lock on `db->lock`, XOR `current` vs `db->buf[db->active]` into `delta_out` using 8-byte (uint64_t) operations in a stride loop, unlock.
    - `apply_delta`: XOR `delta` with `prev_keyframe` into `output` using 8-byte operations (no locking — this is the iPad decode side, single-threaded).
    - `update_keyframe_reference`: copy keyframe into pending buffer (`1 - db->active`), take write lock, swap `db->active`, unlock.
