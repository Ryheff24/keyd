<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Verify end-to-end remote desktop on physical devices</name>
  <action>
    Human verifies the complete end-to-end wired display pipeline: Mac screen streaming to iPad over USB NCM with LZ4+delta compression, Metal ProMotion rendering, QR pairing, TLS/DTLS encryption, and automatic Wi-Fi/AWDL fallback.

    **Setup:**
    1. Connect iPad to Mac via USB-C cable
    2. Launch RemoteDesktopAgent on Mac (grant Screen Recording + Accessibility when prompted)
    3. Launch RemoteDesktopApp on iPad
    4. Scan QR code from Mac's "Pair iPad..." menu

    **Test 1 - Wired Streaming:**
    1. After QR scan, Mac screen should appear on iPad within 1-2 seconds
    2. Verify: full Retina resolution, correct colors, no tearing
    3. Move windows, play a video - verify smooth motion at high frame rate
    4. Check HUD (swipe down from top): should show USB icon + latency + FPS

    **Test 2 - Transport Failover:**
    1. Unplug USB-C cable
    2. Verify: Mac screen continues on iPad within 2 seconds over Wi-Fi
    3. HUD should flash yellow and show Wi-Fi icon
    4. Re-plug cable
    5. Verify: connection promotes back to USB NCM within 2 seconds
    6. HUD should flash green and show USB icon

    **Test 3 - HUD:**
    1. Tap HUD pill - should expand showing mode toggle, resolution, bitrate, disconnect
    2. Wait 3 seconds - HUD should auto-hide
    3. Verify system edge swipes still work (swipe from bottom for home indicator)

    **Test 4 - Mac Menu Bar:**
    1. Verify menu bar shows connection state (USB/Wi-Fi)
    2. Verify "Reset Pairing" works
    3. Verify "Fix Launch at Login" is present

    **Test 5 - Performance (approximate):**
    1. Open Activity Monitor on Mac
    2. Check RemoteDesktopAgent CPU usage during wired streaming (target: less than 3%)
    3. Check GPU usage (target: 0%)
    4. Check RSS memory (target: less than 50 MB)
    5. HUD latency reading (target: less than 8ms wired, less than 25ms wireless)

    **Test 6 - Reconnection:**
    1. Put Mac to sleep, then wake
    2. Verify: auto-reconnect silently
    3. Background iPad app, then foreground
    4. Verify: streaming resumes automatically
    5. During reconnection: verify frozen frame (NOT black screen)
  </action>
  <verify>Type "approved" if all tests pass, or describe specific failures for gap closure.</verify>
  <done>All 6 test categories pass on physical hardware. Phase 2 Foundation is verified complete.</done>
