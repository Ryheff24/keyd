    **SessionManager.swift:**

    `@Observable class SessionManager`:
    - State enum: `awaitingPairing`, `connecting`, `streaming`, `reconnecting`, `disconnected`.
    - Owns: `USBNetworkTransport`, `WirelessTransport`, `QRPairing`, `LZ4Decompressor`, `HEVCDecoder`, `MetalRenderer`, `HUDViewModel`.
    - Transport FSM state: `currentTransport: TransportState`.

    `func start()`:
    1. Check `QRPairing.isPaired`. If not, show QR scanner.
    2. If paired, start transport monitoring:
       - `USBNetworkTransport.startMonitoring()` — watch for USB NCM.
       - `WirelessTransport.startBrowsing()` — browse for `_keydrd._tcp`.
    3. On connection established:
       - Parse `SessionHandshakeMessage` from first TCP message.
       - Store display geometry (width, height, scale factor).
       - Initialize decompressor with frame size.
       - Update MetalRenderer viewport.
       - Transition to `streaming`.
    4. Set up frame receive pipeline:
       - `transport.onMediaFrame = { data in self.handleReceivedFrame(data) }`

    `func handleReceivedFrame(_ data: Data)`:
    1. Parse `MediaFrameHeader` from first 24 bytes.
    2. Validate magic == 0x4B44.
    3. Extract payload (remaining bytes).
    4. If HEVC (flags bit0): `hevcDecoder.decode(data: payload, header: header)` -> CVPixelBuffer -> convert to raw pointer -> `metalRenderer.updateFrame(...)`.
    5. If LZ4 keyframe or delta: `lz4Decompressor.decompress(data: payload, header: header, frameBytes: ...)` -> raw pointer -> `metalRenderer.updateFrame(...)`.
    6. Update HUD: increment FPS counter, update latency from probe.

    Reconnection (user decision: frozen frame + "Reconnecting..." overlay):
    - On disconnect: set state to `reconnecting`. Do NOT clear last frame (frozen frame for visual continuity).
    - Exponential backoff: 0.5s, 1s, 2s, 4s, 8s max.
    - "Retry Now" available via HUD or overlay button.
    - On Mac sleep/wake: auto-reconnect silently (no HUD flash per user decision).
    - On app foreground: auto-resume streaming.

    **ContentView.swift:**

    ```swift
    struct ContentView: View {
        @State var sessionManager: SessionManager

        var body: some View {
            ZStack {
                Color.black.ignoresSafeArea() // True black for OLED letterbox

                switch sessionManager.state {
                case .awaitingPairing:
                    QRScannerView(pairing: sessionManager.qrPairing,
                                  onPaired: { sessionManager.onPairingComplete() })
                case .connecting:
                    VStack {
                        ProgressView()
                        Text("Connecting...")
                    }
                case .streaming, .reconnecting:
                    MetalRenderView(renderer: sessionManager.metalRenderer)
                        .ignoresSafeArea()
                    if sessionManager.state == .reconnecting {
                        ReconnectingOverlay(onRetryNow: { sessionManager.retryNow() })
                    }
                    HUDView(viewModel: sessionManager.hudViewModel)
                case .disconnected:
                    Text("Disconnected")
                }
            }
            .preferredColorScheme(.dark)
            .onAppear { sessionManager.start() }
        }
    }
    ```

    `MetalRenderView`: UIViewRepresentable wrapping MTKView. Sets up MetalRenderer on appear.

    `QRScannerView`: UIViewRepresentable wrapping AVCaptureVideoPreviewLayer. Straight to camera viewfinder (user decision: no onboarding screen).

    `ReconnectingOverlay`: Semi-transparent overlay with "Reconnecting..." text and "Retry Now" button. Shown over frozen last frame (user decision: NOT black screen).
