  </files>
  <action>
    Create `Shaders.metal` with vertex and fragment shaders for full-screen textured quad.

    **Vertex shader (`vertexShader`):**
    - Input: vertex index (0-3 for full-screen quad).
    - Output: clip-space position + texture coordinates.
    - Generate 4 vertices for a full-screen triangle strip (2 triangles = 1 quad).
    - Texture coordinates: (0,0) top-left to (1,1) bottom-right.
    - Accept a `float4` uniform for viewport rect (x, y, width, height in NDC) to support letterboxing. The vertex positions are mapped to this viewport rect, not the full screen.

    **Fragment shader (`fragmentShader`):**
    - Input: interpolated texture coordinates from vertex shader.
    - Sample from `texture2d<float>` (the BGRA frame texture).
    - Output: `float4` color.
    - The texture is BGRA; Metal's `bgra8Unorm` pixel format handles the channel swizzle automatically so the shader just samples normally.
    - P3 color space is set on the CAMetalLayer, not in the shader. The shader outputs linear values; the layer's color space handles the gamut mapping.

    **Structs:**
    ```metal
    struct VertexOut {
        float4 position [[position]];
        float2 texCoord;
    };

    struct Uniforms {
        float4 viewport; // x, y, width, height in NDC [-1, 1]
    };
    ```

<task type="auto">
  <name>Task 2: MetalRenderer with CAMetalDisplayLink + triple buffering + letterbox</name>
  <files>
    RemoteDesktop/iPadOS/Render/MetalRenderer.swift
  </files>
  <action>
    Create `MetalRenderer.swift`:

    `class MetalRenderer: NSObject`:
    - Properties:
      - `let device: MTLDevice`
      - `let commandQueue: MTLCommandQueue`
      - `let pipelineState: MTLRenderPipelineState`
      - `var displayLink: CAMetalDisplayLink?`
      - `let inflightSemaphore = DispatchSemaphore(value: 3)` — triple buffering (RD-REND-03)
      - `var frameTexture: MTLTexture?` — the current frame to render (BGRA)
      - `var macDisplayWidth: Int = 0`, `var macDisplayHeight: Int = 0` — from session handshake
      - `var viewportRect: CGRect = .zero` — computed letterbox viewport

    - `init()`:
      - `MTLCreateSystemDefaultDevice()`
      - Create command queue.
      - Build render pipeline descriptor with vertex function "vertexShader" and fragment function "fragmentShader" from default library. Set `colorAttachments[0].pixelFormat = .bgra8Unorm`.
      - Create pipeline state.
      - Pre-allocate frame texture with `.bgra8Unorm`, size = max expected resolution (will resize on session handshake).

    - `func setup(metalLayer: CAMetalLayer)`:
      - Set `metalLayer.device = device`.
      - Set `metalLayer.pixelFormat = .bgra8Unorm`.
      - Set `metalLayer.colorspace = CGColorSpace(name: CGColorSpace.displayP3)` (RD-REND-02).
      - Set `metalLayer.maximumDrawableCount = 3` (triple buffering).
      - Create `CAMetalDisplayLink(metalLayer: metalLayer)` (RD-REND-01).
      - Set display link delegate.
      - Add display link to RunLoop.main, mode: .common.
      - NOTE: `CADisableMinimumFrameDuration = YES` in Info.plist was set in Plan 01. Without it, this caps at 60Hz per Pitfall 5.

    - `func updateFrame(_ data: UnsafeRawPointer, width: Int, height: Int)`:
      - If texture size doesn't match, recreate texture.
      - `texture.replace(region:mipmapLevel:withBytes:bytesPerRow:)` with `bytesPerRow = width * 4`.
      - This is the entry point from the decode pipeline — called after LZ4 decompress or HEVC decode.

    - `func computeViewport(screenBounds: CGRect)`:
      - Aspect-fit calculation per research code example:
      - `macAspect = macDisplayWidth / macDisplayHeight`
      - `screenAspect = screenBounds.width / screenBounds.height`
      - If macAspect > screenAspect: full width, letterbox top/bottom (user decision: landscape fill = full width).
      - Else: full height, pillarbox left/right.
      - Store computed rect in `viewportRect`.
      - Convert to NDC for shader uniform.
      - Background color is true black (0,0,0,1) — tandem OLED pixels off (user decision).

    - CAMetalDisplayLink delegate callback (the render loop):
      1. `inflightSemaphore.wait()` — block if 3 frames already in flight.
      2. Get next drawable from metal layer.
      3. Create command buffer.
      4. Create render pass descriptor with drawable's texture as color attachment, load action `.clear` with black.
      5. Create render command encoder.
      6. Set pipeline state, vertex buffer (viewport uniforms), fragment texture (frameTexture).
      7. Draw triangle strip (4 vertices).
      8. End encoding.
      9. `commandBuffer.present(drawable)`.
      10. `commandBuffer.addCompletedHandler { _ in self.inflightSemaphore.signal() }`.
      11. `commandBuffer.commit()`.

    - Handle orientation changes: recalculate viewport on `viewWillTransition(to:)` or bounds change. Both landscape and portrait supported (RD-APP-04). iPad Pro 11" and 13" (RD-APP-05) — no hardcoded dimensions, use actual screen bounds.
