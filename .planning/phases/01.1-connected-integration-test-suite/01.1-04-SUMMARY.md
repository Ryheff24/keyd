## Decisions Made
- Used `"$mac_binary" --test-mode &` (direct binary path) instead of `open -n "$mac_app_bundle"` — the `open` command does not forward CLI arguments to the launched process, so `--test-mode` would never reach `CommandLine.arguments`
- Did not call `load_devices()` in test-integration mode — that function requires `IOS_DEVICES` or `IPAD_DEVICE`/`IPHONE_DEVICE` pairs for multi-device deploy flows; test-integration only needs a single `IPHONE_DEVICE` read directly from env
- Agent lifecycle: kill before (port conflict prevention) + kill after (teardown), with `sleep 1` before start and `sleep 0.5` after kill for bind/unbind stability
