## Decisions Made

- **No AppDelegate**: app uses `@main struct KeydApp: App`, not `UIApplicationDelegate`. `TransportManagerRegistry` singleton fills the role.
- **NotificationCenter for message observation**: avoids modifying the production `switch message { }` dispatch in `handleIncomingMessage`; the `notifyTestObservers()` call is a no-op in production (no observers).
- **IntegrationTestCase.swift NOT shared into XCTest target**: sharing as a source file caused duplicate symbol errors since the types are also compiled in the host app. Using `@testable import KeydApp` from the harness is the correct approach.
- **SuiteCHarness separate from IntegrationHarness**: `IntegrationHarness` imports `XCTest` (for `XCTAttachment`), which cannot be imported in the main app target. `SuiteCHarness` conforms to the same `IntegrationHarnessProtocol` without `XCTest`.
- **`beforeSend` on `awaitMessage`**: observer registered first, send triggered second — eliminates the race where a fast Mac reply arrives before the observation is set up.
