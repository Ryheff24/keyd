**Step 2 — TransportTestRunner.swift:**

```swift
@MainActor
class TransportTestRunner: ObservableObject {
    @Published var results: [ScenarioResult] = []
    @Published var isRunning = false

    struct ScenarioResult: Identifiable {
        let id: String           // Scenario ID
        let passed: Bool
        let stepsExecuted: Int
        let invariantViolations: [String]
        let eventTrace: [TransportEventEntry]
        let failureDetail: String?
    }

    func runAll() async { /* iterate allScenarios, call runScenario for each */ }
    func runScenario(_ scenario: TransportTestScenario) async -> ScenarioResult { /* ... */ }
}
```

The `runScenario` method:
1. Sets `state = scenario.initialState`
2. Creates a `TransportEventLog` to capture the trace
3. For each event in `scenario.events`:
   a. Calls `agentTransportTransition(from: state, on: event)`
   b. Records transition in the event log
   c. Runs each invariant from `scenario.invariants` — if any fails, records violation and optionally continues or stops
4. After all events, checks `state == scenario.expectedFinalState`
5. Returns `ScenarioResult` with the full event trace

For stress scenarios, the runner caps at a configurable step limit and checks convergence within bounded time.
