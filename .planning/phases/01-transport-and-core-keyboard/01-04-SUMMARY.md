# Phase 1 Plan 04: QR Pairing + Dynamic Island Live Activity Summary

**One-liner:** Curve25519 ECDH QR pairing with Keychain storage + ActivityKit Widget Extension for Dynamic Island connection status.

## What Was Built

### QR Pairing Security Model

**macOS side** (`macOS/KeydAgent/Pairing/PairingManager.swift`):
- Generates Curve25519 key pair on demand
- `generatePairingQRPayload()` returns JSON: `{publicKeyBase64, port:12345, agentID, version:1}`
- `completePairing(iOSPublicKeyData:deviceID:)` performs ECDH, derives shared secret via HKDF-SHA256
- Stores shared secret in macOS Keychain under `com.ryheff.keyd.agent` service key

**macOS QR display** (`macOS/KeydAgent/UI/QRCodeView.swift`):
- `QRCodeWindowView` renders QR via `CIFilter.qrCodeGenerator()` at 10x scale using NSCIImageRep

**iOS side** (`KeydApp/KeydApp/Pairing/PairingManager.swift`):
- Decodes QR JSON payload, validates version == 1
- Generates iOS Curve25519 key pair
- Sends `KeydMessage.pairingRequest(PairingRequest)` to macOS via TransportManager
- Completes ECDH with macOS public key, derives same shared secret via HKDF-SHA256
- Stores shared secret + macOS public key in iOS Keychain under `com.ryheff.keyd.app`
- `init()` checks Keychain to set `isPaired` — enables auto-connect on subsequent launches

**iOS QR scanner** (`KeydApp/KeydApp/UI/PairingView.swift`):
- `QRScannerView` (UIView + AVCaptureMetadataOutputObjectsDelegate) scans with AVCaptureSession
- One-shot scan: stops session after first QR, fires haptic feedback
- `PairingView` (SwiftUI) wraps scanner with dark background + progress/error states

### Dynamic Island Live Activity

**Shared attributes** (`KeydApp/KeydApp/LiveActivity/KeydConnectionAttributes.swift`):
- `KeydConnectionAttributes: ActivityAttributes` with `KeydConnectionContentState`
- Status enum: `.usb` (green), `.awdl` (yellow), `.connecting` (orange), `.disconnected` (red)
- Each status has `color: Color`, `label: String`, `shortLabel: String`

**Main app lifecycle manager** (`KeydApp/KeydApp/LiveActivity/KeydLiveActivity.swift`):
- `KeydLiveActivityManager` calls `Activity<KeydConnectionAttributes>.request/update/end`
- Guards on `ActivityAuthorizationInfo().areActivitiesEnabled` before starting

**Widget Extension** (`KeydApp/KeydLiveActivity/`):
- `KeydLiveActivityBundle` (`@main`) hosts `KeydLiveActivityWidget`
- `ActivityConfiguration(for: KeydConnectionAttributes.self)` with DynamicIsland builder:
  - Compact leading: color dot
  - Compact trailing: latency ms or shortLabel
  - Minimal: color dot
  - Expanded leading: status label + color dot
  - Expanded trailing: latency + reconnect `Link(destination: "keyd://reconnect")`
  - Expanded bottom: "keyd — macOS keyboard bridge" tag
  - Lock Screen banner: status + latency + reconnect button

**TransportManager integration** (`KeydApp/KeydApp/Transport/TransportManager.swift`):
- `State` enum now conforms to `Equatable`
- `connectionState` has `didSet` that calls `updateLiveActivity(for:)`
- USB connected → start or update activity with `.usb` status
- AWDL connected → start or update with `.awdl` status
- Connecting → no-op (don't show activity yet)
- Disconnected → `liveActivityManager.end()`

**App launch gate** (`KeydApp/KeydApp/App/KeydApp.swift`):
- Shows `PairingView` when `!pairingManager.isPaired`
- Shows `RootView` (keyboard) when `pairingManager.isPaired`
- `.onReceive(pairingManager.$isPaired)` triggers `transportManager.start()` after pairing
- `.onOpenURL` handles `keyd://reconnect` from Dynamic Island reconnect button

## Pairing Flow Test Result

Flow verified via code review (physical device test requires signed build):
1. Fresh install — `PairingManager.init()` finds no Keychain entry → `isPaired = false`
2. App shows `PairingView` → camera scanner active
3. macOS agent generates QR payload with Curve25519 public key
4. iOS scans QR → ECDH completes → Keychain entry written → `isPaired = true`
5. `RootView` (keyboard) appears
6. Second launch — `PairingManager.init()` finds Keychain entry → `isPaired = true` → keyboard direct

## Dynamic Island Test Result

Dynamic Island requires physical iPhone 14 Pro or later. Code review confirms correct Widget Extension architecture:
- `@main` in `KeydLiveActivityBundle` (extension target only)
- `ActivityConfiguration<KeydConnectionAttributes>` with `dynamicIsland:` closure
- `DynamicIsland { ... } compactLeading: { ... } compactTrailing: { ... } minimal: { ... }`
- Lock Screen banner view with `.activityBackgroundTint`

## Keychain Behavior

- Shared secret stored as `kSecClassGenericPassword` items
- iOS: service=`com.ryheff.keyd.app`, two accounts: `shared-secret` + `mac-agent-public-key`
- macOS: service=`com.ryheff.keyd.agent`, account: `shared-secret`
- SecItemDelete called before SecItemAdd to handle re-pairing cleanly
